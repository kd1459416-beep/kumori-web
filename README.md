# fog(くもりガラス)

カメラに映った自分が、湯気でくもった鏡になります。
親指と人さし指を摘んで動かすと描けて、グーで動かすと大きく拭けます。
パソコンに息を吹きかけると、またくもります。

## 動かし方

```bash
cd kumori-web
pip install -r requirements.txt
python app.py
```

ブラウザで http://127.0.0.1:5000 を開きます（自動で /fog に遷移します）。「カメラとマイクをはじめる」を押して、カメラとマイクの許可を聞かれたら「許可」を選んでください。

### スマホで試すとき

カメラは `https` か `localhost` でしか使えません。同じWi-Fiにつないで、次のように起動します。

```bash
python app.py --https
```

表示された `https://(パソコンのIPアドレス):5000` をスマホで開きます。

## 操作

| 動き・キー | すること |
| --- | --- |
| 親指と人さし指を摘んで動かす　｜　描く（指を開くと止まる） |
| グーで動かす | 大きく拭く |
| パソコンに「はぁ〜」と息を吹きかける／Space キー長押し | くもる |
| C キー　｜　描いたものを消して、くもらせる |
| S キー／右下のシャッター　| 写真を撮ってギャラリーに保存 |
| Esc キー　｜　スタート画面に戻る　｜
| 左下の brush | 筆の太さ |
| 右下の gallery | ギャラリーを開く |

## ファイル

```
kumori-web/
├── app.py                  Flask サーバー（画面を配る・写真の保存・一覧・削除）
├── requirements.txt        必要な部品(Flask, Pillow, pyoenssl)
├── docs/                   コードの解説
├── photos/                 撮った写真（自動でできる・Git には入れない）
│   └── thumbs/             一覧用の小さい画像（自動でできる）
├── templates/
│   └── gallery.html        ギャラリーの画面
└── static/
　   └── fog.html           鏡アプリ本体（見た目・動き・手の検出・くもりの計算）
```

カメラ映像と手の検出は、すべてブラウザの中で動きます。
サーバーに送られるのは、シャッターを押した写真1枚だけです。

Lilian Chiu さんの fog mirror を参考にしています。
